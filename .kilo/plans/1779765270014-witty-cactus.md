# Plan: Modern Theme Overhaul for Ceylon Track

## Problem Statement

The current theme system has readability issues:
- Low contrast text/background combos (dark navy text on dark blue backgrounds)
- Gradient `body-bg` washes out text contrast (`linear-gradient(135deg, #0A0F1E, #1B6CA8)`)
- Inconsistent font families across pages (DM Sans + Syne vs Inter)
- Hardcoded colors in pages (e.g. `schedules.html` has `rgba(255,255,255,0.97)` header — white on dark themes)
- Dark themes use `#00D4FF` cyan accent on `#0A0F1E` navy bg — harsh, eye-straining
- Sunset theme has amber text on warm brown — very low contrast (~3:1)
- No spacing or radius scale — each page invents its own values
- Legacy variable aliases create bloat (25 vars per theme, many unused)

## Proposed Solution

Replace all 4 themes with 3 clean, high-contrast, modern themes using Inter font system-wide. Define a unified spacing/radius scale. Remove all gradient backgrounds, hardcoded colors, and legacy aliases.

## New Theme System Design

### Three Themes

| Theme   | `data-theme` | Vibe              | Target |
|---------|-------------|--------------------|--------|
| Dark    | `dark`      | Slate/gray dark    | Default, eye comfort in low light |
| Light   | `light`     | Warm white/soft    | Daytime, high readability |
| Amber   | `amber`     | Warm dark accent   | Low-blue-light evening use |

### Font System

- **Primary**: `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`  
  *(Replaces DM Sans + Syne — Inter has superior readability at small sizes, better hinting)*
- **Monospace**: `'JetBrains Mono', 'Fira Code', monospace` (for code/timestamps if needed)
- **Base size**: `16px`, line-height `1.65`
- **Heading line-height**: `1.25`

## Implementation Plan

### Phase 1: Write new `theme.css` (single file, ~250 lines)

Replace `frontend/css/theme.css` entirely with:
1. **CSS reset** (box-sizing, margin, scroll-behavior) — shared base
2. **Typography defaults** — Inter font, base size, line-heights, heading weights
3. **Theme blocks** — `body[data-theme="dark"]`, `body[data-theme="light"]`, `body[data-theme="amber"]`
4. **Spacing + radius variables** (theme-independent)
5. **Component utility classes** (`.card`, `.btn`, `.btn-primary`, `.badge`, `.input-field`, `.divider`)
6. **Legacy alias block at bottom** — map old `--bg`, `--surface`, `--text`, etc. to new vars for backward compatibility

### Phase 2: Rewrite `theme-loader.js`

Current issues:
- Reads from localStorage first, then API — API overwrites localStorage on every load (flickers)
- Only supports 4 hardcoded themes
- No system preference auto-detection

New version:
1. Check user profile from `localStorage.getItem('ceylon_track_user')` for `theme_preference` first (no API call needed)
2. Fallback to `localStorage.getItem('ceylon_track_theme')`
3. Fallback to `window.matchMedia('(prefers-color-scheme: dark)')` → 'dark' / 'light'
4. Apply theme BEFORE first paint (inline script in `<head>`)
5. Expose `window._ct.setTheme(name)`, `_ct.getCurrentTheme()`, `_ct.getValidThemes()`
6. Valid themes: `['dark', 'light', 'amber']`

### Phase 3: Replace Google Fonts

Current pages individually import DM Sans + Syne or Inter. New system:
- Import **Inter** once via `<link>` in `<head>` OR via `@import` in `theme.css`
- Use `@import url(...)` in `theme.css` so all pages get it automatically
- Remove individual font imports from all page `<head>` sections
- Replace `DM Sans`/`Syne` references with Inter in all inline CSS

### Phase 4: Refactor All 14 HTML Pages

For **each page**, make these changes:

1. **Remove page-specific Google Fonts `<link>`** — provided by theme.css
2. **Replace `font-family: var(--font-body)`** → `font-family: 'Inter', sans-serif` (now a constant, not a variable per theme)
3. **Replace `font-family: var(--font-display)`** → `font-family: 'Inter', sans-serif`
4. **Replace old CSS variable names** → new ones (see mapping below)
5. **Remove hardcoded colors** like `rgba(255,255,255,0.97)`, `linear-gradient(135deg, ...)`
6. **Replace hardcoded pixel values** with spacing/radius variables for consistency
7. **Remove `transition: background 0.3s, color 0.3s`** from body — add it globally in theme.css
8. **Remove page-specific `font-family: 'Inter'` declarations** — now inherited from theme.css
